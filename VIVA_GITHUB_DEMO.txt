========================================
HOW TO SHOW GITHUB DURING VIVA
========================================

TIMING: First 2 minutes of viva
--------------------------------

STEP 1: Open Browser
--------------------
□ Open Chrome/Firefox
□ Go to: https://github.com/misterperfect9737-arch/hospital-management-system

STEP 2: Show Repository to Proctor
-----------------------------------
□ Point to repository name
□ Show it's PUBLIC (important!)
□ Show the description
□ Show README.md is displayed

STEP 3: Show Files
------------------
□ Scroll down to show all files:
  - app.py
  - models.py
  - routes.py
  - requirements.txt
  - README.md
  - templates/
  - static/

STEP 4: Show Collaborators (if added)
--------------------------------------
□ Click "Settings" tab
□ Click "Collaborators"
□ Show AppDev team members added

STEP 5: Show Commits
---------------------
□ Click "Commits" (shows your commit history)
□ Show "Initial commit" message

========================================
WHAT PROCTOR WILL CHECK:
========================================

✅ Repository is PUBLIC
✅ All project files are present
✅ README.md is visible
✅ Collaborators are added (AppDev team)
✅ Code is properly organized

========================================
COMMON QUESTIONS & ANSWERS:
========================================

Q: When did you create this repository?
A: [Check the commit date and say it]

Q: Who are the collaborators?
A: AppDev team members [show the list]

Q: Is this your own code?
A: Yes, this is my Hospital Management System project

Q: Can you show me the main application file?
A: [Click on app.py and show the code]

========================================
TIME: 2 minutes maximum
========================================

Then move to next step: Extract ZIP and run app
