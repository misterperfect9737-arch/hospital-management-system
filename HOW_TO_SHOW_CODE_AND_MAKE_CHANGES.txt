PART 3: HOW TO MAKE CODE CHANGES
========================================

SCENARIO 1: Simple Text Change
-------------------------------
Proctor: "Change the homepage title to 'ABC Hospital'"

STEP 1: Find the file
□ Open templates/index.html

STEP 2: Find the text
□ Press Ctrl + F (Find)
□ Search for: "Hospital Management System"
□ It will highlight the text

STEP 3: Change it
□ Replace with: "ABC Hospital"
□ Press Ctrl + S to save

STEP 4: Show the change
□ Go to browser
□ Refresh page (F5)
□ Say: "Here is the updated title"

SCENARIO 2: Change a Number
----------------------------
Proctor: "Change the phone number validation to 11 digits"

STEP 1: Find the file
□ Open routes.py

STEP 2: Find the code
□ Press Ctrl + F
□ Search for: "len(phone)"
□ You'll find: if len(phone) != 10:

STEP 3: Change it
□ Change 10 to 11
□ if len(phone) != 11:
□ Press Ctrl + S to save

STEP 4: Test it
□ Restart application (Ctrl+C in CMD, then python app.py)
□ Try registering with 11-digit phone
□ Say: "Now it accepts 11 digits"

SCENARIO 3: Add a New Field
----------------------------
Proctor: "Add email field to doctor profile"

STEP 1: Think first!
□ Take 10 seconds to think
□ Say: "I need to add email to Doctor model and template"

STEP 2: Add to model
□ Open models.py
□ Find: class Doctor
□ Add line: email = db.Column(db.String(100))
□ Save

STEP 3: Add to template
□ Open templates/admin/doctors.html
□ Find where other fields are shown
□ Add: <td>{{ doctor.email }}</td>
□ Save

STEP 4: Explain
□ Say: "I've added email field to Doctor model and template"
□ Say: "To see it work, I need to reset database"
□ (Usually proctor won't ask you to actually test it)

========================================
PART 5: STEP-BY-STEP FOR ANY CHANGE
========================================

When proctor asks you to make a change:

STEP 1: LISTEN CAREFULLY
□ Let them finish speaking
□ Understand what they want

STEP 2: THINK (10 seconds)
□ Which file to change?
□ What exactly to change?
□ Will it break anything?

STEP 3: EXPLAIN YOUR PLAN
□ Say: "I need to change [filename]"
□ Say: "I will modify [what]"
□ This shows you understand!

STEP 4: MAKE THE CHANGE
□ Open the file
□ Find the code (use Ctrl+F)
□ Make the change
□ Save (Ctrl+S)

STEP 5: TEST (if needed)
□ Restart app if needed
□ Show it works
□ Explain what you did

STEP 6: IF SOMETHING BREAKS
□ Don't panic!
□ Say: "Let me check the error"
□ Undo the change (Ctrl+Z)
□ Try again or explain the issue

========================================
PART 6: USEFUL KEYBOARD SHORTCUTS
========================================

In VS Code / Notepad:
□ Ctrl + F = Find text
□ Ctrl + H = Find and replace
□ Ctrl + S = Save file
□ Ctrl + Z = Undo
□ Ctrl + Y = Redo
□ Ctrl + / = Comment/uncomment line

In Browser:
□ F5 = Refresh page
□ Ctrl + Shift + R = Hard refresh (clear cache)

In CMD:
□ Ctrl + C = Stop application
□ Up Arrow = Previous command
