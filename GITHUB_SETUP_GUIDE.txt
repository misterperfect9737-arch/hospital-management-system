========================================
GITHUB SETUP - STEP BY STEP
========================================

PART 1: CREATE REPOSITORY ON GITHUB
------------------------------------

STEP 1: Go to GitHub
□ Open browser
□ Go to: https://github.com
□ Login to your account

STEP 2: Create New Repository
□ Click green "New" button (top left)
  OR go to: https://github.com/new

STEP 3: Fill Repository Details
□ Repository name: hospital-management-system
□ Description: Hospital Management System with Flask
□ Select: ✅ Public (IMPORTANT!)
□ DO NOT check "Add README" (you already have one)
□ DO NOT add .gitignore
□ DO NOT add license
□ Click "Create repository"

STEP 4: Add Collaborators
□ On your new repository page
□ Click "Settings" tab (top right)
□ Click "Collaborators" (left sidebar)
□ Click "Add people" button
□ Search for AppDev team members
□ Add each one as collaborator
□ They will receive email invitation

========================================
PART 2: PUSH CODE TO GITHUB
========================================

STEP 1: Open CMD in Your Project Folder
□ Press Windows Key + R
□ Type: cmd
□ Press Enter
□ Type: cd "C:\hosipital final"

STEP 2: Initialize Git (if not already done)
□ Run: git init

STEP 3: Add All Files
□ Run: git add .

STEP 4: Create First Commit
□ Run: git commit -m "Initial commit - Hospital Management System"

STEP 5: Connect to GitHub
□ Copy the URL from GitHub (looks like):
  https://github.com/YOUR_USERNAME/hospital-management-system.git

□ Run: git remote add origin YOUR_GITHUB_URL
  (Replace YOUR_GITHUB_URL with the URL you copied)

STEP 6: Push to GitHub
□ Run: git branch -M main
□ Run: git push -u origin main

STEP 7: Enter Credentials (if asked)
□ Username: your GitHub username
□ Password: your GitHub personal access token
  (NOT your regular password!)

========================================
IF GIT NOT INSTALLED:
========================================

1. Download Git from: https://git-scm.com/download/win
2. Install with default settings
3. Restart CMD
4. Try again from PART 2

========================================
IF YOU NEED PERSONAL ACCESS TOKEN:
========================================

1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Give it a name: "Hospital Project"
4. Check: ✅ repo (all permissions)
5. Click "Generate token"
6. COPY THE TOKEN (you won't see it again!)
7. Use this token as password when pushing

========================================
VERIFY IT WORKED:
========================================

□ Go to: https://github.com/YOUR_USERNAME/hospital-management-system
□ You should see all your files
□ README.md should be displayed
□ Check collaborators are added
