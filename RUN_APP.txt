========================================
HOW TO RUN APP IN CMD - STEP BY STEP
========================================

STEP 1: OPEN CMD
----------------
Press Windows Key + R
Type: cmd
Press Enter

STEP 2: GO TO PROJECT FOLDER
-----------------------------
cd "C:\hosipital final"

STEP 3: CHECK PYTHON IS INSTALLED
----------------------------------
Try these commands ONE BY ONE until one works:

python --version
py --version
python3 --version
C:\Python314\python.exe --version

If NONE work, you need to install Python first!

STEP 4: INSTALL DEPENDENCIES
-----------------------------
Use the command that worked above:

Option A (if "python" worked):
python -m pip install -r requirements.txt

Option B (if "py" worked):
py -m pip install -r requirements.txt

Option C (if full path worked):
C:\Python314\python.exe -m pip install -r requirements.txt

STEP 5: RUN THE APP
-------------------
Use the same command that worked:

Option A:
python app.py

Option B:
py app.py

Option C:
C:\Python314\python.exe app.py

STEP 6: OPEN BROWSER
--------------------
Open any browser and go to:
http://localhost:5000
OR
http://127.0.0.1:5000

========================================
IF PYTHON NOT INSTALLED:
========================================

1. Go to: https://www.python.org/downloads/
2. Download Python 3.11 or 3.12
3. Run installer
4. ✅ CHECK "Add Python to PATH" (IMPORTANT!)
5. Click Install
6. Restart CMD
7. Try again from STEP 3
