========================================
🔧 HOW TO INSTALL PYTHON - SIMPLE GUIDE
========================================

YOUR PYTHON IS NOT WORKING!
You MUST fix this before viva!

========================================
STEP-BY-STEP INSTALLATION
========================================

STEP 1: Download Python
------------------------
□ Open browser
□ Go to: https://www.python.org/downloads/
□ Click the big yellow button "Download Python 3.12.x"
□ File will download (about 25 MB)

STEP 2: Install Python
----------------------
□ Find downloaded file (usually in Downloads folder)
□ Double-click to run installer
□ ⚠️ VERY IMPORTANT: CHECK the box "Add Python to PATH"
   (This is at the BOTTOM of the installer window)
□ Click "Install Now"
□ Wait for installation (2-3 minutes)
□ Click "Close" when done

STEP 3: Restart Computer
-------------------------
□ Close all windows
□ Restart your computer
□ This is IMPORTANT for PATH to work!

STEP 4: Test Python Works
--------------------------
□ Press Windows Key + R
□ Type: cmd
□ Press Enter
□ Type: python --version
□ Press Enter
□ Should show: Python 3.12.x

If it shows Python version = SUCCESS! ✅
If it says "not found" = Try next step

STEP 5: Alternative Test
-------------------------
If "python" doesn't work, try:
□ Type: py --version
□ Press Enter
□ Should show: Python 3.12.x

If "py" works, use "py" instead of "python" in all commands!

========================================
AFTER PYTHON IS INSTALLED
========================================

TEST YOUR APP:
--------------
□ Open CMD
□ cd "C:\hosipital final"
□ python -m pip install -r requirements.txt
  (or: py -m pip install -r requirements.txt)
□ python app.py
  (or: py app.py)
□ Open browser: http://localhost:5000

If app runs = YOU'RE READY FOR VIVA! ✅

========================================
TROUBLESHOOTING
========================================

PROBLEM: "python is not recognized"
SOLUTION: 
1. You didn't check "Add Python to PATH"
2. Uninstall Python
3. Install again and CHECK the box!
4. Restart computer

PROBLEM: Installation fails
SOLUTION:
1. Run installer as Administrator
2. Right-click installer → "Run as administrator"

PROBLEM: Still not working
SOLUTION:
1. Use "py" instead of "python" in all commands
2. py --version
3. py -m pip install -r requirements.txt
4. py app.py
