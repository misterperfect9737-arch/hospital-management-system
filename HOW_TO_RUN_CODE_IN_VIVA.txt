========================================
HOW TO RUN CODE LIVE IN VIVA
========================================

You have 2 OPTIONS to run your code.
I'll show you BOTH - pick the one you're comfortable with!

========================================
OPTION 1: USING CMD (RECOMMENDED!)
========================================

This is EASIER and what most students do.

STEP-BY-STEP:
-------------

STEP 1: Open CMD
□ Press Windows Key + R
□ Type: cmd
□ Press Enter
□ A black window opens (Command Prompt)

STEP 2: Navigate to Your Project
□ Type: cd "C:\hosipital final"
□ Press Enter
□ You're now in your project folder

STEP 3: Install Dependencies (First Time)
□ Type: python -m pip install -r requirements.txt
□ Press Enter
□ Wait 2-3 minutes (packages installing)
□ You'll see "Successfully installed..."

STEP 4: Run Your Application
□ Type: python app.py
□ Press Enter
□ You'll see:
  * Running on http://127.0.0.1:5000
  * Running on http://localhost:5000

STEP 5: Open Browser
□ Open Chrome/Firefox
□ Type in address bar: http://localhost:5000
□ Press Enter
□ Your website opens!

STEP 6: Keep CMD Open
□ DON'T close CMD window
□ Keep it visible on screen
□ Proctor can see app is running

STEP 7: To Stop Application (When Done)
□ Click on CMD window
□ Press: Ctrl + C
□ App stops

WHAT TO SAY DURING THIS:
------------------------
"I'm opening Command Prompt"
"Navigating to my project folder"
"Installing dependencies - this takes 2-3 minutes"
"Now running the application"
"Application is running on localhost port 5000"
"Opening browser to show the website"
"Here is my Hospital Management System"

========================================
OPTION 2: USING VS CODE TERMINAL
========================================

This is CLEANER - everything in one window!

STEP-BY-STEP:
-------------

STEP 1: Open VS Code
□ Open VS Code
□ File → Open Folder
□ Select: C:\hosipital final
□ Your project opens

STEP 2: Open Terminal in VS Code
□ Click "Terminal" in top menu
□ Click "New Terminal"
□ OR press: Ctrl + ` (backtick key)
□ Terminal opens at bottom of VS Code

STEP 3: Check You're in Right Folder
□ Terminal should show: C:\hosipital final>
□ If not, type: cd "C:\hosipital final"

STEP 4: Install Dependencies (First Time)
□ Type: python -m pip install -r requirements.txt
□ Press Enter
□ Wait 2-3 minutes

STEP 5: Run Your Application
□ Type: python app.py
□ Press Enter
□ You'll see: * Running on http://127.0.0.1:5000

STEP 6: Open Browser
□ Ctrl + Click on the URL in terminal
□ OR manually open browser: http://localhost:5000

STEP 7: Split Screen (COOL!)
□ Now you have:
  - Left side: Your code files
  - Bottom: Terminal running app
  - Browser: Website running
□ Proctor can see everything!

STEP 8: To Stop Application
□ Click in terminal area
□ Press: Ctrl + C

WHAT TO SAY DURING THIS:
------------------------
"I'm opening VS Code with my project"
"Opening integrated terminal"
"Installing dependencies"
"Running the application"
"Here you can see the code, terminal, and running app"
"Let me open the browser to show the website"

========================================
COMPARISON: CMD vs VS CODE
========================================

CMD (Command Prompt):
✅ Simple and straightforward
✅ Everyone knows how to use
✅ Less chance of confusion
✅ Recommended for beginners
❌ Need separate windows for code/terminal

VS Code Terminal:
✅ Everything in one window
✅ Looks more professional
✅ Easy to switch between code and terminal
✅ Can click URLs directly
❌ Slightly more complex

MY RECOMMENDATION: Use CMD if this is your first viva!

========================================
TROUBLESHOOTING DURING VIVA
========================================

PROBLEM 1: "python" command not found
--------------------------------------
TRY THESE:
□ py app.py
□ python3 app.py
□ C:\Python314\python.exe app.py

SAY: "Let me try alternative Python command"

PROBLEM 2: Dependencies won't install
--------------------------------------
TRY:
□ py -m pip install -r requirements.txt
□ python -m pip install flask flask-sqlalchemy flask-login

SAY: "Let me install packages individually"

PROBLEM 3: Port already in use
-------------------------------
ERROR: "Address already in use"

FIX:
□ Press Ctrl + C
□ Close any other CMD windows
□ Try again: python app.py

SAY: "Port was busy, let me restart the application"

PROBLEM 4: Browser won't open localhost
----------------------------------------
TRY:
□ http://127.0.0.1:5000
□ Check if app is running in CMD
□ Restart app

SAY: "Let me try the IP address instead"

PROBLEM 5: Import errors
-------------------------
ERROR: "No module named flask"

FIX:
□ Install again: pip install flask
□ Check Python version: python --version

SAY: "Let me reinstall the required package"
